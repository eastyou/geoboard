# geoboard

[![CI](https://github.com/eastyou/geoboard/actions/workflows/ci.yml/badge.svg)](https://github.com/eastyou/geoboard/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.9%2B-brightgreen.svg)](pyproject.toml)

给小学数学课堂用的几何钉板生成器：一条命令生成 A4 纵向、按毫米精确打印的钉板纸与面积/周长挑战卡。**零第三方依赖，不联网，打印即用。**

每块钉板都是正方形点阵，钉点用清晰的实心圆表示，外框是实线，方便学生用橡皮筋围图形，或用铅笔在钉点之间连线。挑战卡只写题目与难度星级，不给答案，适合动手操作、同伴互讲和课堂闯关。

## 特性

- **3~10 点阵**：`--size 5` 生成 5×5，共 25 个钉点，相邻钉点间距随规格自动计算
- **毫米级排版**：每块钉板外框 112 mm 见方，四周留 13 mm 边距，默认 5×5 时钉点间距 21.5 mm，够橡皮筋和铅笔操作
- **实心钉点 + 实线外框**：SVG 中钉点为黑色实心圆，外框为 0.7 mm 实线，打印后边界清楚
- **自动分页**：1~4 块钉板，每页最多 2 块；单块独占一页时自动居中
- **规格标注**：每块钉板下方写明「钉点数 N×N」，钉板页页脚重复规格与纸张方向
- **16 题挑战库**：面积、周长、图形三类，难度 1~3 星，只给题目，不给答案
- **种子复现**：`--seed` 控制挑战卡顺序，同一种子生成完全相同的页面
- **A4 纵向**：挑战卡每页 4 张，虚线边框便于裁剪；每页都有页码
- **自包含页面**：HTML/CSS/SVG 全部内联，无脚本、无外链、无网络字体
- **屏幕自适应**：窄屏自动改为单列流式布局，不横向溢出
- **严格校验**：参数越界、类型错误、标题为空都会中文报错，退出码 2
- **137 个单元测试**：覆盖钉点数量与坐标、点阵边界、分页、题库去重、种子复现、参数边界、HTML 转义、SVG 尺寸与 CLI 退出码

## 安装

```bash
pip install geoboard
```

也可以直接下载源码，在项目目录里运行：

```bash
python -m geoboard --help
```

要求 Python 3.9 及以上，不需要安装任何第三方库。

## 用法

生成默认页面（2 块 5×5 钉板 + 4 张挑战卡）：

```bash
python -m geoboard -o 几何钉板.html
```

完整示例：

```bash
python -m geoboard \
  --size 5 \
  --boards 2 \
  --challenges 4 \
  --seed 42 \
  --title 几何钉板 \
  -o examples/几何钉板.html
```

### 参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--size` | 每边钉点数 N，生成 N×N 点阵，范围 3~10 | `5` |
| `--boards` | 生成几块钉板，范围 1~4；每页最多 2 块，超出自动分页 | `2` |
| `--challenges` | 生成几张挑战卡，范围 0~8；`0` 表示不生成 | `4` |
| `--seed` | 随机种子，控制挑战卡顺序 | `42` |
| `--title` | 页面标题，最多 40 个字符 | `几何钉板` |
| `-o, --output` | 输出 HTML 路径 | `几何钉板.html` |

### 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 生成成功 |
| `1` | 写入文件失败（目录不存在、没有权限等） |
| `2` | 参数或数据不合法（越界、类型错误、标题为空等） |

## 打印说明

用浏览器打开生成的 HTML，按 `Ctrl/Cmd + P`：

1. 纸张：**A4 纵向**
2. 边距：**无**
3. 缩放：**100% / 实际大小**，不要选「适合页面」
4. 勾选「背景图形」，挑战卡的浅色标签才会打印

钉板页直接使用，不需要裁剪。挑战卡页沿**虚线**剪开，每页 4 张，可以整页裁成 4 张小卡。

如果希望反复使用，可以把钉板页打印在较厚的纸上并过塑；学生用可擦笔或细橡皮筋操作，擦掉后还能继续练。

## 课堂玩法

1. **数钉点**：先让学生数一数每块钉板有多少个钉点，再读出下方「钉点数 5×5」。
2. **围面积**：用橡皮筋或铅笔围出 1 格、2 格、4 格；再挑战「面积为 2 格的正方形」这类需要斜着围的图形。
3. **比周长**：围出面积相同但形状不同的图形，数一数周长差多少，讨论「面积一样，周长不一定一样」。
4. **抽卡闯关**：把挑战卡剪开，按星级分组；学生抽卡后在钉板上画，画完向同伴说明自己的画法。
5. **同伴互评**：不直接公布答案，让同桌检查「钉点是否都落在交叉点上」「面积/周长是否符合题目」，再说说理由。

挑战卡只提供题目和难度，不提供答案，方便老师根据学生水平追问和引导。挑战卡按 5×5 及以上钉板设计；用 3×3 或 4×4 时可先做简单的自由探索。

## 项目结构

```text
geoboard/
├── geoboard/
│   ├── __init__.py     # 对外 API
│   ├── __main__.py     # python -m geoboard
│   ├── cli.py          # 参数解析、退出码、写文件
│   ├── model.py        # 钉点坐标、分页布局、挑战题库
│   └── render.py       # SVG 钉板、A4 HTML 排版
├── tests/
│   ├── test_model.py   # 坐标、边界、分页、题库与参数校验
│   ├── test_render.py  # SVG 尺寸、页数、转义与打印样式
│   └── test_cli.py     # 命令行边界与退出码
├── examples/           # 示例页面
├── .github/workflows/ci.yml
├── LICENSE
├── README.md
└── pyproject.toml
```

## 开发

运行全部单元测试：

```bash
python -m unittest discover -s tests
```

运行单个测试文件：

```bash
python -m unittest discover -s tests -p "test_model.py" -v
```

重新生成示例：

```bash
python -m geoboard --size 5 --boards 2 --challenges 4 --seed 42 \
  --title 几何钉板 -o examples/几何钉板.html
```
